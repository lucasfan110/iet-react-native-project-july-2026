# IET React Native Project

This is a mobile application for viewing AggieFeed, the campus posting system
for UC Davis. It shows a list of feed, and the user can click on the feed to see
more details about them.

## Setup

1. Clone the repository, using
   `git clone https://github.com/lucasfan110/iet-react-native-project-july-2026.git`.
2. Download all the packages, using `npm install` or `yarn install`.
3. Download emulators, [XCode](https://developer.apple.com/xcode/) if you are on
   MacOS or [Android Studio](https://developer.android.com/studio) if you are
   using Windows/Linux.

## Running the App

1. Run `npm start` or `yarn start`.
2. Type `i` for iOS emulator or `a` for Android emulator.

## Libraries Used

- [React Navigation](https://www.npmjs.com/package/@react-navigation/native)
- [React Query](https://www.npmjs.com/package/@tanstack/react-query)
- [axios](https://www.npmjs.com/package/axios)
- [he](https://www.npmjs.com/package/he)
